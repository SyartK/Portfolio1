Hey, I'm Syart. I live in Preševo and build web products across the stack. My current focus is PHP, Laravel, Livewire, JavaScript, MySQL, AWS, Tailwind CSS, and clean interfaces that are easy to use.

I like building things that work the first time and look honest doing it. No fluff, no animation for animation's sake. Just measured, deliberate UI.
